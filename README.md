# Радиофест-2025 · Песочница «Мишени»

> Виртуальный тренировочный стенд по номинации **«Радионавигация»**
> предварительного тура Радиофест-2025 (НИУ МИЭТ).
> Полностью браузерный, без USB и реального железа: симулятор LimeSDR + Python-REPL (Pyodide) + сцена с мишенями.

**Live:** https://blessblissmari.github.io/radiofestmironovartem/

## Что внутри

| Панель | Что делает |
| --- | --- |
| ① **Сцена** | Полигон 3×3, активная мишень подсвечивается и «пульсирует». Танк, выстрелы, попадания, отметки попаданий. |
| ② **Эфир / SDR** | Спектр, водопад, осциллограммы I/Q + констелляция, фазометр (DF). Переключение SDR-X / SDR-Y и антенн 0/1. Live-декодер AM/OOK. |
| ③ **Python REPL** | Полноценный Python (Pyodide) + `numpy`. Мок-`SoapySDR`, который читает семплы из того же симулятора, что и панель «Эфир». Готовые примеры от «Hello SDR» до полного решения. |
| ④ **Брифинг** | Условия задачи, физические формулы и подсказки, API мока, ссылки на оригинальные регламенты. |
| Шапка — **Судья** | Стартует раунд, выдаёт код, считает время и штрафы, фиксирует объявление номера и попадания. |

## Параметры стенда (соответствуют регламенту)

* Несущая 2,6 ГГц, AM-OOK, длительность бита 250 мкс.
* 8 ASCII-символов, преамбула `~`.
* 9 мишеней 3×3, стенка 1,5 × 1 м, удаление 2,5 м.
* 2 SDR × 2 антенны: SDR-X (азимут), SDR-Y (угол места), разнос 5 см.
* Регламентные штрафы: ошибочный номер +60 с, доп. боеприпасы +10 с за пару, тайм-аут 3 мин.

## Как тренироваться

1. Открой live-страницу.
2. Нажми **▶ Старт раунда** — судья выдаст код в шапке.
3. Найди этот код в эфире (вкладки «Спектр», «Водопад», «I/Q», «Live-декодер»).
4. Переключайся между **SDR-X** и **SDR-Y**, на вкладке «Фазометр (DF)» прочитай Δφ.
5. По формулам из подсказок (или примером из Python-вкладки `04` / `05`) посчитай номер мишени.
6. Введи номер в поле «Заявить судье №» → **Объявить**.
7. Выбери мишень в селекторе сцены → **🚀 ОГОНЬ**. Цель — выиграть за минимальное время.
