Задача (Радиофест-2025, «Радионавигация»)

      
На стене расположено 9 мишеней (сетка 3 × 3). Каждая по очереди излучает 8-символьное
      сообщение (первый символ — ~), AM-OOK, длительность импульса 250 мкс,
      несущая 2,6 ГГц.

      
Судья называет команде один из 9 кодов. Команда обязана:

      
    
        
  1. Принять эфир двумя SDR (X — антенны разнесены по азимуту, Y — по углу места).
    2. 
        
  2. Определить, какая из мишеней передаёт заданный код, по фазовой разности.
    3. 
        
  3. Объявить номер судье.
    4. 
        
  4. Поразить эту мишень из танка.
    5. 
      

      
Штрафы: ошибочный номер +60 с, доп. боеприпасы +10 с за пару, всего 3 минуты на раунд.

    


    

      
Физика и алгоритм

      
    
        
  • λ = c/f ≈ 0,1154 м при 2,6 ГГц.
    • 
        
  • Антенны разнесены на d = 5 см, поэтому ±π·sin(θ)·d/λ ⇒ Δφ ∈ ≈ ±π·0,43·sin(θ).
    • 
        
  • Стена 1,5 × 1,0 м, удаление 2,5 м. Колонки → азимут ≈ 0°, ±17°. Строки → угол места 0°, ±11°.
    • 
        
  • OOK-демодуляция: env(t) = |I + jQ|, порог = (max+min)/2, по 250 мкс на бит.
    • 
        
  • Пеленг (фазовый интерферометр): Δφ = ∠(s₁ · s₀*), усреднять по битам где env=1.
    • 
        
  • Грид: после Δφ_x → азимут → колонка (0/1/2 ↔ −/0/+), Δφ_y → угол места → строка.
    • 
        
  • Номер мишени: row · 3 + col + 1 (нумерация слева-направо, сверху-вниз).
    • 
      

    


    

      
SoapySDR API (мок)


import numpy as np, SoapySDR
from SoapySDR import SOAPY_SDR_RX, SOAPY_SDR_CF32

sdr = SoapySDR.Device({"driver":"lime", "index":0})  # 0 = SDR-X, 1 = SDR-Y
sdr.setSampleRate(SOAPY_SDR_RX, 0, 200e3)
sdr.setFrequency(SOAPY_SDR_RX, 0, 2.6e9)
sdr.setGain(SOAPY_SDR_RX, 0, 'LNA', 25)
sdr.setAntenna(SOAPY_SDR_RX, 0, 'LNAH')

st = sdr.setupStream(SOAPY_SDR_RX, SOAPY_SDR_CF32, [0, 1])  # обе антенны
sdr.activateStream(st)
mtu = sdr.getStreamMTU(st)
b0 = np.zeros(mtu, np.complex64); b1 = np.zeros(mtu, np.complex64)
sdr.readStream(st, [b0, b1], mtu)
sdr.deactivateStream(st); sdr.closeStream(st)
